📚 Library Management System

A responsive web-based Library Management System built for managing books, users, and transactions. This system supports book issuance, returns, fine calculation, and admin control — all through a user-friendly interface.



 📌 Project Overview

The Library Management System is designed to simplify library operations digitally. It allows students to browse books, issue/return them, while the admin can manage book records, user data, and transactions with ease. Fine calculation is automated based on the return date.

Developed using HTML, CSS, JavaScript, MySQL, and PHP.



🛠️ Tech Stack

Technologies    used

Frontend     | HTML, CSS, JavaScript               
Backend      | PHP                                 
Database     | MySQL                               
Hosting (Local) | XAMPP / WAMP                     



 ✅ Key Features

 👤 Student login & book browsing
📘 Book issuance and return system
⏱️ Auto fine calculation for late returns
📦 Book inventory management
🔐 Admin login for secure access
📊 Admin panel to manage books, users, and transactions
📱 Responsive UI for better usability
